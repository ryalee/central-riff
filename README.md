# 🎸 Central Riff

Além da tecnologia, também me aventuro pelo mundo da música e toco minha guitarra sempre que dá. Por isso fiz esse site com ferramentas essenciais para guitarristas. 
É um projeto extremamente simples que conta com metrônomo, afinador (em breve) e um sistema de busca de tablatura (redireciona a pagina da musica no songsterr)

## Features

- **Busca de Tablaturas:** Integração via Server Actions do Next.js para pesquisa instantânea de tablaturas oficiais do Songsterr.
- **Metrônomo** Motor de áudio construído com a Web Audio API (modelo lookahead) para garantir estabilidade rítmica sem atrasos (drift), com tratamento robusto de ciclo de vida e estados de áudio.
- **Afinador** Em desenvolvimento, ta ruim ainda.

## Stack

Este projeto foi construído utilizando tecnologias modernas de desenvolvimento web:

- **Framework:** Next.js
- **Linguagem:** TypeScript
- **Estilização:** Tailwind CSS
- **Áudio:** Web Audio API (Nativa)
